# Team Blues – CodeGuide

A guided learning application that helps users work through problems one step at a time using questions and hints.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Planned Features

- Select a problem from a curated problem library
- Work through guided questions one step at a time
- Receive hints when needed
- Save responses and progress
- View a summary of the completed solution path
